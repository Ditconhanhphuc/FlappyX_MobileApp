# 🐦 Flappy Bird Clone with Flutter & Flame

A simple and fun **Flappy Bird** clone built using [Flutter](https://flutter.dev) and the [Flame game engine](https://flame-engine.org/). This project showcases the capabilities of Flutter in game development and provides a clean, modular structure for anyone interested in building 2D games.

## 🚀 Features

- Smooth gameplay mechanics
- Pixel-perfect collision detection
- Dynamic obstacle generation
- Score tracking and game over screen
- Responsive design for multiple screen sizes

## 🛠️ Tech Stack

- **Flutter** – Cross-platform UI toolkit
- **Flame** – Lightweight 2D game engine for Flutter
- **Dart** – Programming language used with Flutter

## 🔧 Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/flappy_bird_flutter.git
   cd flappy_bird_flutter

2. **Install dependencies:**

   ```bash
   flutter pub get

3. **Run the game:**

   ```bash
   flutter run
